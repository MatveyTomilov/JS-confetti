# JS-confetti

Небольшой JavaScript-модуль, который запускает полноэкранную анимацию падающего конфетти и декоративных лент на HTML5 Canvas.

## Возможности

- Автоматически добавляет контейнер анимации в `<body>`.
- Рисует конфетти и ленты на отдельном Canvas.
- Использует фиксированный полноэкранный слой, который не перехватывает клики.
- Подстраивает размер Canvas при изменении размеров окна.
- Запускается через метод `confetti.run()`.

## Требования

- Браузер с поддержкой ES-модулей и HTML5 Canvas.
- jQuery.
- Сборщик JavaScript, который умеет обрабатывать импорты модулей (например, Vite или Webpack).

В репозитории нет собственного `package.json` и конфигурации сборки: модуль рассчитан на подключение к существующему фронтенд-проекту.

## Подключение

Установите jQuery в основном проекте, если он ещё не установлен:

```bash
npm install jquery
```

Добавьте модуль в точку входа приложения:

```js
import confetti from './js/confetti.js';

confetti.run();
```

Модуль сам дождётся готовности DOM перед созданием Canvas. Если используете готовую точку входа из этого репозитория, `app.js` уже импортирует jQuery, подключает модуль и запускает анимацию после готовности документа.

## Как это работает

При вызове `run()` модуль:

1. Создаёт контейнер `#confetti`, если его ещё нет.
2. Добавляет стили полноэкранного слоя.
3. Создаёт Canvas и запускает цикл анимации с частотой около 30 кадров в секунду.
4. Обновляет размер Canvas при изменении размера окна.

**Важно:** вызывайте `run()` один раз на страницу. В текущей версии публичный метод остановки анимации не предусмотрен.

## Ограничения текущей версии

- Параметры количества частиц, цветов и скорости пока заданы внутри исходного кода.
- Нет отдельного API для остановки и повторного запуска анимации.
- Нет встроенной настройки отключения анимации для пользователей с системным предпочтением `prefers-reduced-motion`.
